# claude-code-learnings

Field-tested Claude Code configuration patterns, pipeline designs, and operational learnings from daily use across a multi-repo engineering workspace.

This is not configuration reference — it's the decisions behind the configuration and the traps that cost hours to find.

## What's here

- **[harness-playbook.md](harness-playbook.md)** — The complete playbook: architecture decisions, permission model, hooks, commands, agent design, memory system, and a 12-item anti-pattern catalog. Each pattern includes the rationale and failure mode that motivated it.

## Who this is for

Anyone running Claude Code as a daily driver who wants to go beyond the defaults. The playbook is organized as a portable reference for auditing and improving a Claude Code installation on any machine — read a section, decide if it applies, adapt the concept.
